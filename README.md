
# 🖊️ Detectar Caneta Azul

Projeto simples em Python utilizando **OpenCV** e **NumPy** para detectar objetos de cor azul (especificamente uma caneta) em tempo real através da webcam.

## 🚀 Tecnologias Utilizadas

* Python 3.x
* OpenCV (`cv2`)
* NumPy

## 📦 Como Instalar e Rodar

1. Certifique-se de ter o Python instalado no computador.
2. Instale as bibliotecas necessárias abrindo o terminal e executando:
   ```bash
   pip install opencv-python numpy

```

3. Baixe ou clone este repositório.
4. Execute o script principal:
```bash
python nome_do_arquivo.py

```


*(Substitua `nome_do_arquivo.py` pelo nome do seu arquivo Python).*

## 🎮 Como Usar

* Assim que a janela da webcam abrir, posicione uma caneta azul em frente à câmera.
* O programa vai rastrear a cor, desenhar um retângulo verde ao redor dela e exibir o rótulo **"Caneta"**.
* Para fechar o programa, pressione a tecla **`q`** no teclado.
